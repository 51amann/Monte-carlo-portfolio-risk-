# Monte Carlo Portfolio Risk & VaR Engine

## Project Overview

A Python-based quantitative finance project that uses Monte Carlo simulation to model potential portfolio returns and analyze investment risk.

## Current Features

- Historical stock price collection using Yahoo Finance.
- Daily stock return calculations.
- Portfolio allocation using NumPy.
- Weighted portfolio return calculations.
- Monte Carlo random return generation.
- Visualization of simulated return distributions.

## Technologies Used

- Python
- NumPy
- Pandas
- Matplotlib
- yfinance
- SciPy

## Current Development Stage

Phase 1: Historical data processing and Monte Carlo return generation.

## Upcoming Features

- Portfolio value simulation.
- 10,000 simulated portfolio paths.
- Value at Risk (VaR).
- Expected Shortfall.
- Portfolio risk visualization.
- Correlation and covariance modelling.

## Disclaimer

This project is for educational and research purposes. Simulated outcomes are not investment predictions or financial advice.
